# Changelog

## 2.1.0

- Auto naming preset: any common low/high/cage convention, any case, suffix / prefix / CamelCase.
- Visibility buttons work on `_High` / `_Low` scenes; all name checks share one detector.

## 2.0.1

- Suffix matching is case-insensitive (`_High` / `_Low` scenes now work).
- Added HP / LP naming preset.

## 1.0.1

- Packaged as a Blender Extension.
- Added high/low poly name-pair creation workflow.
- Added collection organization tools.
- Added visibility and swap utilities for bake setup.
